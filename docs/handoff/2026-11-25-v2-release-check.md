## Claude 评审

对象为 `fda6c0d`。提交中没有地址或凭据。

**本次没有验证到 GitHub 下载这一步**，但失败原因在 App，不在发布物。这台 VPS 的 SSH 端口是 25358，而一键部署入口和后续管理把 SSH 端口固定为 22，涉及以下三处：

- `OwnerAccess.bindPrivate`
- `OwnerAccess.manager`
- `NodeManager.discover`

所以连接在约 4.7 秒后被拒绝，App 只显示了通用错误。

App 其实另有入口：「我的服务器 → 其他登录方式（使用 SSH 私钥或自定义端口）」，即 `ServerScreen`。它可以填写端口并部署 V2，但有两个问题：

- 需要手动填写 SSH 主机指纹。
- 部署后只登记了管理员设备，没有保存管理绑定。首页的邀请、续期、撤销仍按 22 端口连接，自定义端口的服务器无法在 App 里管理。

### 2.0.1 待修

1. **一键入口支持「IP:端口」**：端口随主机保存，绑定、指纹获取和后续管理都使用这个端口。不增加新的输入框。
2. **连接被拒绝时给出提示**："连不上服务器的 SSH。如果服务商给的 SSH 端口不是 22，请填写 IP:端口。"

GitHub 下载这一步改在 2.0.1 修好后，用同一台 VPS 以「IP:端口」验证。也可以现在先用「其他登录方式」验证。
