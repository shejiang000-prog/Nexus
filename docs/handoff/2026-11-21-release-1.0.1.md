# Android 1.0.1 小修

分支 `release/1.0.1` 来自 `main@aa000f9`。

## 改动

- 原先 HTTP 状态异常、响应内容无效和网络异常共用一条失败提示。现在手动查询公网出口时，ipinfo.io 的 429 和 403 分别提示限流和拒绝查询。其他 HTTP 错误显示实际站点和状态码，非 200 响应不读正文。
- 收到 200 后，出口诊断检查 JSON 中的 IP 是否为 IPv4 或 IPv6 字面量，网页诊断检查正文是否含有 Example Domain。响应内容不符时提示该站点的内容无法识别。DNS、连接及读取超时继续使用原有网络错误提示。
- 已核对 `TunnelService.monitorExit`：非 200、网络或解析异常会得到空结果，跳过写入和变化通知。本次只加一行注释；后台沿用原有的 IP 字符检查。
- README 常见问题补充了没有 IPv6 出口时少数游戏和 P2P 应用的限制。版本更新为 1.0.1，CHANGELOG 有唯一的对应版本标题。
