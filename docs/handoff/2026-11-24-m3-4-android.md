## Claude 评审

评审对象为开发分支 `ca1fd9b`（基线 `ed6ad58`）和规范分支 `b9f18f4`。

### 复核结果

- NexusLab 从 `ca1fd9b` 导出源码，重新执行 `go vet` 和 `go test -race -count=1 ./...`：11 个包全部通过，两个安装测试按设计跳过。新增的 `TestOpenFlowsSurviveIdle` 和 `TestH3NoPingAfterLastTunnel` 也在其中。
- 用上一轮评审的独立测试 `TestZZIdleOpenFlow` 复测：静默 45 秒后，H2 和 H3 都收到了回声。上一轮 H3 在这里失败。
- `tools/test_android_release_download.py` 在 Linux 上 2/2 通过。Windows 上两项都跳过，因为需要 `sh`。
- 在 Windows 用 `m34.aar` 离线执行 `assembleDebug testDebugUnitTest assembleDebugAndroidTest`，构建成功，JUnit 3/3 通过：V2ErrorsTest 1 项，V2ShareValidityTest 2 项。
- 雷电模拟器上的 `share` 用例没有复跑。

### 结论

三项全部达标，没有需要修改的地方。

- **H3 保活**：通过补丁复用 quic-go 原有的保活计时器，按连接计数。TCP 和 UDP 业务的 context 结束后计数会减回去，对端结束发送时也会减。没有业务流时不发 PING，`max_idle_timeout` 仍为 30000 毫秒，指纹不变。
- **wget 备选**：wget 的 `--https-only` 不检查跳转，所以脚本逐跳检查目标是否为 HTTPS。这一步加上 SHA-256 校验，足够安全。
- **分享有效期**：天数框初始为空，「永久」开关打开时输入框禁用，没选有效值时按钮不可点。永久和有期限可以双向互改，续期的起算点正确。

### 提示，不需要本轮修改

- 续期使用页面顶部的天数或「永久」设置，点设备行的「续期」即按该设置生效。M4 真机试用时确认这样是否直观。
- Release 包部署时从 GitHub 下载节点程序，需要已发布的同版本标签。所以 M4 先用内置程序的 Debug 包部署，下载路径在正式发布后用真实标签部署一次来确认。
