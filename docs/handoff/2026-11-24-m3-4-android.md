# M3 第 4 部分 · Android 小修

开发基线 `ed6ad58`，规范基线 `f850fce`。

| 改动 | 实测结果 |
|---|---|
| H3 静默业务 | 每条 QUIC 连接只在有已建立的 TCP 流或 UDP 会话时保活，静默 15 秒发 PING。基线在 45 秒后两种 H3 业务均写入失败。修复后 H2、H3 的 TCP 和 UDP 都在原连接上收到第二次回声，四例各 45.24 秒，竞态检测通过。 |
| 无业务的 H3 | 最后一条流结束后，在服务端逐帧统计客户端 PING，随后完整 30 秒为 **0**。实采握手的 `max_idle_timeout` 仍为 30000 毫秒，既有握手测试通过。此前已启动的雷电空闲窗口实测 600.069 秒，客户端报文 0、应用层请求 0。 |
| Release 部署 | 服务器优先使用 curl，缺少 curl 时使用 GNU Wget。每次跳转都要求 HTTPS，连接超时 15 秒，整次下载限时 300 秒。执行前核对 APK 内置 SHA-256。离线命令替身覆盖两条下载路径、降级跳转和传输失败，另通过发布摘要检查。公网下载留待 M4。 |
| 分享有效期 | 天数框初始为空，可输入 1–3650 天，打开「永久」会禁用输入框。未选有效值时邀请和续期均禁用。按天续期从当前账号到期日和服务器时间的较晚者算起，永久改按天从服务器时间算起。App 生成的领取链接最长 7 天。 |

雷电的 `share` 单项用例通过。实际创建并兑换永久邀请，同一设备先改为 1 天、再改回永久。两次均通过 VPN 回声，并核对节点到期值和首页显示。日期显示为「2026-11-25 21:33 到期」，改回后显示「长期有效」。测试使用实际管理控件和实验室账本，管理命令通过本地测试通道执行。输入范围及续期起算另有两个快速单元断言组。

首次 Android 编译发现一处管理命令的 JSON 参数尚未转成文本，修正后离线构建通过。分享用例最初使用无障碍点击，曾在控件切换时误读旧状态，改为实际触摸并等待按钮状态后通过。已卸载本轮两个测试包、关闭雷电实例 0，并清理 NexusLab 临时节点。

复查入口为 `TestOpenFlowsSurviveIdle`、`TestH3NoPingAfterLastTunnel`、`tools/test_android_release_download.py` 和 `tools/verify_android_v2_lab.py --phase share`。
