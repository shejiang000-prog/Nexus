# PC-UI-1 · Windows 流量统计与节点测速

基线 `bb81e51`，开发分支 `v2/m0-transport`。两个 Tauri 命令均已加入 `permissions/core.toml` 的 `control-core`。本轮没有新增依赖或修改 `apps/desktop/ui`。

## 界面调用约定

| 命令 | 参数 | 成功结果 | 边界行为 |
| --- | --- | --- | --- |
| `traffic_stats` | 无 | `[up_bytes, down_bytes]`，本次连接的累计业务字节 | 新连接从零开始，H3/H2 切换沿用原计数。未就绪、正在断开或已断开时返回错误码 `not_connected`。 |
| `probe_nodes` | `{subscriptionId}` 或 `{v2:true}`，二选一 | 订阅按已保存的顺序返回 `[[nodeId, ms或null], …]`，V2 返回 `[["v2", ms或null]]` | 握手失败、超时、预算内未轮到的节点均为 `null`。V2 尚未登记也返回 `[["v2",null]]`。 |

壳在启动核心时传 `trafficStats:true`。核心在 Xray 的 SOCKS、HTTP、TUN 业务入口计数，含直连和代理的应用负载，排除控制握手、封装和重复转发的 DNS 字节。旧壳省略标记时，核心沿用旧管道格式。数值有变化时每秒最多推送一次，状态行只有两个累计数。界面轮询只读取壳内缓存。

测速使用独立的短时核心进程，读取 DPAPI 订阅快照或已有 V2 登记及 CNG 密钥。套接字复用物理出口绑定。TLS 和 Reality 校验对端，Reality 失败后立即退出；Hysteria2 完成 QUIC 握手；明文 TCP 入口测 TCP 建连。V2 复用固定公钥的 H3/H2 线路握手，不兑换邀请。测速结果和状态管道只传节点 ID 和整数毫秒或 `null`，不记录节点地址。单节点 3 秒，最多 8 个工作者，核心整批 9 秒，壳从接到调用起限时 10 秒。同一窗口进程已有一批测速时，新的调用返回 `probe_busy`。

**Claude 界面衔接。** 现有字段可直接使用。`sampleTraffic()` 对所有异常都会关闭本窗口的后续采样。若轮询恰逢断开，建议单独处理 `not_connected`，清掉上次采样并等待下一次连接。测速可给 `probe_busy` 提示「正在测速，请稍候」，给 `probe_failed` 提示「测速未完成，请重试」。

## 快速验收

固定源码 Windows x64 核心及 Tauri release 壳均已离线构建。NexusLab 使用一次性登记、合成订阅、独立 Windows 数据目录和指定回环 SOCKS 端口。

| 验收 | 实测结果 |
| --- | --- |
| 流量统计 | V2（本次业务连接为 H2）和 Reality 订阅各发 65,536 B，实验回显服务各收到 65,536 B，回包逐字节一致。两次会话的累计值均从 `[0,0]` 增至 `[65536,65536]`。 |
| 节点测速 | 连接保持期间，V2 返回 331 ms，含子进程启动共 0.407 s。另一批 Reality 返回 41 ms，同时接受 TCP 后不完成握手的合成节点返回 `null`，整批 3.093 s。两次探测前后，隔离档案的文件列表和 SHA-256 完全一致。 |

Tauri 的 mock runtime 使用实际命令及应用权限配置，核对了已连接的数组、未连接的错误码、空档案 V2 返回值及互斥参数校验。联网验收覆盖 SOCKS、V2 和 Reality；HTTP、TUN、Hysteria2 未做独立实网验收。测试身份、订阅、临时邀请已清理，实验进程已退出。本机系统代理、TUN、DNS 和防火墙均未改动。

本机配套壳与核心位于 `E:\temp\nexus-pcui1-out`。两项验收可用 `E:\temp\nexus-pcui1-qa` 的 `bridge.py`、`fixture.py`、`verify.py` 重建隔离实验并复跑；每次使用新的实验邀请和临时档案。

## Claude 评审

结论：**通过**。

复现：`--test-routing --test-tun` 下核心、助手和 DNS 保护测试全部通过，`cargo test` 3/3 通过，debug 和 release 壳都能构建。联网验收采信本交接。

代码检查：
- 流量只统计三个业务入口的载荷链路，控制面和封装不计入；壳只缓存核心推送的两个累计数，界面轮询不碰核心，开销低。
- 测速使用独立短时进程，单个节点 3 秒、整批 9 秒、壳侧 10 秒，三层限时。Reality 补丁在测速模式下校验失败即退出，不会去访问回落网站。结果只包含节点 ID 和毫秒数。
- 界面按建议补上了处理：`not_connected` 只清空本轮采样，不再关掉网速面板；`probe_busy` 和 `probe_failed` 有对应的中文提示。

未覆盖：HTTP、TUN 入口的计数和 Hysteria2 测速没有实网验证，等 PC 版真实验收时一起测。
