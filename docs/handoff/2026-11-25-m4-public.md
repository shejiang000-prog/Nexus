# M4 公网实测

2026-11-24 晚（北京时间）。开发基线 `d667947`，规范基线 `ebb7bc9`。使用内置 Linux 节点程序的 Debug 包和雷电实例 0。公网部署成功，UDP 故障切换未达标，重启后的客户端自动重连未验收通过。

| 项目 | 实测结果 |
|---|---|
| VPS-A 一键部署 | Debian 13，未填域名。点击到 App 完成 **142.4 秒**。V2、Reality 均已启动。 |
| VPS-B 一键部署 | Ubuntu 24.04，使用对应的 sslip.io 域名。雷电和 Windows 直连 SSH 超时，首次操作失败。雷电经 VPS-A 的 V2 连接重试，V2、Reality、Hysteria2 均已启动，App 进入 B 的管理页。点击到节点记录管理员设备兑换为 **约 176.4 秒**；界面完成的精确时刻未采到。启用 A 是额外操作，B 的直连一键部署未通过。 |
| 网页及测速 | VPS-A 上 Android WebView 经 V2/H3 渲染出 Example Domain 页面。两个协议各下载同一份 11,094,114 字节 HTTPS 文件三次，每次校验字节数与 SHA-256。V2/H3 为 **10.72、11.03、10.19 Mbps**，中位数 **10.72 Mbps**；Reality 为 **2.00、1.31、3.09 Mbps**，中位数 **2.00 Mbps**。 |
| UDP 443 封锁 | VPS-A 只封锁一次。热切换以封锁准备信号为起点，**35.590 秒**后 H2 的新 HTTPS 请求成功。旧 H3 连接上的请求在 **2.560 秒**首次失败，业务连续性和 5 秒门槛未通过。冷启动至首个成功 HTTPS 请求为 **6.913 秒**，超过 3 秒。解封后持续业务观察 **160 秒**未见回到 H3。热切换未取得从防火墙规则实际生效起算的精确耗时。已核实本次临时防火墙表为零。 |
| 续期与撤销 | App 通过 VPS-A 的真实 SSH 创建永久邀请，雷电领取。在第一轮授权核对后补验首页，改为 1 天时显示 **2026-11-25 23:45 到期**，改回后显示 **长期有效**。两次均以原设备认证，日期与账本相符。撤销后新认证被拒。 |
| 独立客户端 | NexusLab 已有的锁定版官方 Xray 使用 App 签发的 VPS-A Reality 分享链接，通过系统证书验证并取得 HTTPS 200。 |
| 重启 | 两台各重启一次，都核对了新的系统启动标识。A 的两项协议服务、B 的三项协议服务均自动恢复。A 的验收驱动在重启导致 SSH 断开时提前结束，随后重新启动连接能打开网页，自动重连缺少有效观测。驱动已修正。B 在重启前就无法从雷电直连，未形成可观察的原会话。 |

部署时发现，有域名的默认配置还需手动勾选两个兼容协议，管理页也缺少签发兼容链接的入口。本轮已修正，管理员仍可取消预选。首次 SSH 指纹确认仅按本轮授权在两台测试机上自动接受，产品保留首次确认及换钥拒绝。

两台节点保持运行。真机目录已保存独立 Debug APK、两条未兑换的 V2 邀请和 VPS-B 的两条兼容分享链接。Hysteria2 与 Clash 的客户端验证留给真机环节，Release 下载留到正式标签发布后。雷电上的本轮两个测试包已卸载，实例 0 已关闭。
