# Android 2.0.1 自定义 SSH 端口验收

「我的服务器」原有 IP 框支持 IPv4:端口及 [IPv6]:端口。省略端口时使用 22，已有绑定和加密管理密钥可直接沿用。首次核对主机身份、密码部署和后续密钥管理都使用同一端口。SSH 拒绝连接时提示检查端口，连接超时保留原提示。

## 实测结果

- 两项 Release 单元测试通过。地址解析覆盖 IPv4、IPv6、自定义端口、显式 22 和非法端口；错误提示覆盖拒连、超时、认证失败和其他网络错误。
- 雷电 emulator-5554 安装本地测试签名的 2.0.1（20001）通用 Release。VPS 使用 Debian 13，在普通入口填 IP 加端口 25358 和密码，域名留空。经服务商控制台核实 SSH 指纹后完成部署，V2 和 Reality 均启动。演练包使用 v2.0.0 节点资产；VPS 下载暂存文件及最终安装文件的 SHA-256 均与已发布的 amd64 文件一致。
- 重开 App 后，在「我的服务器」选择「永久」并生成了一次邀请。连接页显示「IP 模式 · H3 已连接」。雷电自带浏览器启动时崩溃，改用系统 WebView 在 VPN 下打开 Example Domain。页面标题和多语言正文已渲染；辅助检查另要求匹配特定 H1，此断言未通过。

## 发现与收尾

首次 Release 在密码认证前失败。R8 移除了 JSch 通过反射调用的密码和公钥认证构造方法，已补上两条保留规则；上述通过结果来自修复后的常规 Release 构建，只有本次节点资产版本使用演练覆盖值。

VPS 原有 nginx 占用 TCP 和 UDP 443，手动停止后会被自动拉起。经用户同意，验收期间临时阻止重启。测后已移除临时设置，确认 nginx 已恢复、自启且重新监听 TCP 和 UDP 443。本次安装的 V2 保留数据，已停止并取消自启以让出 443；Reality 仍在独立端口运行。已卸载本轮两个测试包并关闭雷电实例 0。
